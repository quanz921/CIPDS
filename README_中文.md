# CIPDS 分析代码与纯合成演示包

本包用于审阅真实分析代码并运行虚构数据演示。**不含任何真实医院或 NHANES 个体记录、不含真实医院训练模型，不能独立复算论文真实数值。**

示例由手写常数与随机种子生成，没有抽样、打乱、加噪或拟合真实患者数据。所有演示输出标注 synthetic。分析源代码包括本次权重修正和新增敏感性分析。

安装 R 依赖后运行 python run_demo.py --rscript "Rscript.exe完整路径" --threads 23。演示使用较少折数、树数、调参组合和协变量，只验证列明流程能执行，不表示整篇研究已复算。

上传仅使用最终 ZIP。不要附研究工作目录、真实数据、模型、日志或旧 Git 历史。.gitignore 不会自动移除已被 Git 跟踪的敏感文件。

正文两处可用性声明应按 docs/DATA_AND_CODE_AVAILABILITY.txt 调整；此代码仓库不修改论文正文。真实复核需机构批准及受控环境。公开 NHANES 由读者从 CDC 获取。
